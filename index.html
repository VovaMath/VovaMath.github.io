Wyzant Mail Watcher (Personal)

Wyzant Mail Watcher (Personal) is a local Windows utility for an individual tutor's own Google account. It checks Gmail metadata for newly received Wyzant notifications and sends a signal to the owner's existing Codex chat. The chat then handles notifications according to the owner's instructions.

This is a personal utility, not a public email service. It is not affiliated with or endorsed by Google, Wyzant, or OpenAI.
